# base-conhecimento

Base de conhecimento das reuniões da **AFATEC / AFACOM**: transcrições
reescritas, sínteses, contexto acumulado por setor e índices de pendências.

**Apenas uma rotina automatizada escreve neste repositório.** Ela roda no
Claude Code, processa as gravações transcritas do Zoom e faz os commits.

⚠️ **Ninguém deve fazer commit manual.** Se mais de uma fonte escrever, o
contexto acumulado entra em conflito e o controle de duplicidade quebra em
silêncio. Sócios apenas consomem (leem) via Project.

Comece por [`_LEIA-PRIMEIRO.md`](_LEIA-PRIMEIRO.md).
